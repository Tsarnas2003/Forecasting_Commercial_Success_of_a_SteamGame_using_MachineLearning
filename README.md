## Data

[Steam Games Dataset (Kaggle, fronkongames)](https://www.kaggle.com/datasets/fronkongames/steam-games-dataset).
It's too large to commit. Download `games.csv` and place it at `proposal-testing/data/games.csv`.

## Layout

- `proposal-testing/label-check.ipynb`: data sanity checks used to pick the label for the proposal
  (header alignment, `User score` coverage, `Estimated owners` thresholds, release-year confound).
